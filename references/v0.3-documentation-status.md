# Version history and evidence status

At the time of the first handoff, only v0.2 code was available and the v0.3 documents were prose-only. The subsequently supplied `maintain-consensus-universal-v0.3.1-2026-10-07.zip` fills that gap. The current executable is v0.3.1; the v0.2 bundle remains beside it for compatibility and version history.

The extracted v0.3.1 package contains `scripts/universal_agent.py`, `scripts/long_horizon_compare.py`, a protocol, a six-step scenario, fixtures, documentation, and two test modules. Its manifest lists 24 files and declares 16 tests. The extracted file list matches the manifest. This is a packaging-integrity check, not evidence that tests pass; the test suite and long-horizon runner were not executed in this packaging update.

The v0.3.1 documentation and source describe postcondition-quality assessment; verification-source authority, independence, mutability, freshness, and coverage checks; and a deterministic long-horizon comparison of a context-only baseline with a context + precheck + external verification flow.

v0.3.1 also adds action-binding fields `serves_purpose`, `action_delta_response`, and `actual_action_source`, plus a system-computed `comparison` that is separate from legacy `divergence_type`. Optional `trigger_rules` cover case selection, metric changes, plan changes, resource scaling, and completion claims. Their default is `record_only`; `external_required` is an explicit stronger setting.

The README specifies Python 3 standard-library dependencies. Do not report included tests as passing unless they have actually been run. The deterministic long-horizon comparison does not establish general model improvement.

## Skill release v0.4

This is a workflow-only release over runtime v0.3.1. It introduces fast and full paths, reuses the current ledger/context across actions, makes `commit`, `check`, and `metrics` conditional, and moves the long-horizon comparison out of routine work. The runtime schema and bundled Python programs are unchanged.
